# PLERA · Art & Image Archive

This directory is the canonical home for artwork created for PLERA's Living Matrix, realms, and memory atlas.

## Organization
- `village/` — village views, residences, social halls and landscapes.
- `mentors/` — approved mentor portraits and related character artwork.
- `galactic/` — space, gateways and exploration artwork.
- `chronicles/` — illustrations for the PLERA stories.
- `originals/` — founder-provided original artwork kept distinct from new interpretations.

## Archival policy
- Keep originals unmodified, with descriptive filenames and source/provenance notes.
- Label generated or newly illustrated artwork distinctly from historically recovered portraits.
- Use relative paths from HTML; optimize website copies separately if needed.
- Do not place personal images or sensitive material here without deliberate review.
- Keep all images under PLERA's existing repository; no remote/CDN dependency.
